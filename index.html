Descripción de la actividad

Alky-Wallet es una billetera digital de demostración construida durante el bootcamp (HTML, CSS, Bootstrap y JavaScript), con pantallas de login, depósito, envío de dinero y transacciones.

Desafío principal

El proyecto llevaba tiempo sin actualizarse: tenía imágenes rotas, un botón que enviaba el formulario por error, y nunca había sido sometido a un proceso de testing formal.

Solución propuesta

Actualicé la interfaz visual manteniendo Bootstrap como base (sin sobre-complicar el diseño), y luego apliqué un proceso de testing manual completo: definí un plan de pruebas, ejecuté 15 casos de prueba funcionales y documenté los defectos encontrados en un repositorio de QA dedicado.

Herramienta técnica utilizada

HTML, CSS y Bootstrap para la interfaz; JavaScript para la lógica simulada; documentación de testing en Markdown, publicado en GitHub.

Principales aprendizajes

Reforcé cómo revisar código ajeno (o propio, de meses atrás) con ojo crítico, cómo documentar defectos de forma clara y reproducible, y cómo priorizar qué mejorar cuando el tiempo es limitado.

Habilidades técnicas aplicadas

Testing funcional manual, diseño de casos de prueba, reporte de bugs, HTML/CSS/Bootstrap, control de versiones con Git.

Por qué elegí este proyecto

Porque combina mis dos perfiles: desarrollo y QA. Muestra que no solo puedo construir una interfaz, sino también evaluarla críticamente, tal como lo haría en un puesto real de Trainee Tech.
