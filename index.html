Descripción de la actividad

API RESTful para una tienda online (usuarios, productos y carritos), construida como proyecto integrador a lo largo de los módulos 6, 7 y 8 del bootcamp. Empezó como un servidor Express básico y terminó como una API completa, con base de datos real y autenticación.

Desafío principal

Entender e implementar autenticación seria en una API: la diferencia entre guardar una sesión en el servidor y usar un token JWT que el cliente reenvía en cada petición, por qué las contraseñas deben guardarse "hasheadas" y no encriptadas, y cómo permitir la subida de archivos (imágenes de producto) sin abrir la puerta a archivos inválidos o demasiado pesados.

Solución propuesta

Construí la API de forma incremental. En el módulo 6 armé la base con Express y un middleware de logging. En el módulo 7 conecté PostgreSQL, primero con consultas SQL manuales y después con Sequelize como ORM, comparando ambos enfoques. En el módulo 8 agregué login con JWT, hash de contraseñas con bcrypt, un middleware que protege las rutas sensibles, y subida de imágenes con Multer, validando tipo de archivo (jpg/png/webp) y peso máximo (2MB).

Herramienta técnica utilizada

Node.js, Express, PostgreSQL, Sequelize, bcryptjs, jsonwebtoken (JWT), multer, dotenv, y Postman para probar manualmente cada endpoint.

Principales aprendizajes

Entendí la diferencia entre autenticación con sesiones y autenticación stateless con JWT, por qué se usa bcrypt específicamente para contraseñas (y no un hash genérico), y cómo separar un backend en capas (rutas → controladores → servicios → repositorios) para que crezca de forma ordenada a medida que se le agregan funcionalidades nuevas.

Métricas de impacto

Más de 15 endpoints documentados, rutas sensibles protegidas con JWT (devolviendo error 401 sin token válido), manejo de conflictos con código 409, y validación de archivos subidos por tipo y tamaño. El proyecto evolucionó sin necesidad de reescribir lo construido en los módulos anteriores.

Habilidades técnicas aplicadas

Node.js, Express, diseño de APIs REST, PostgreSQL, ORM (Sequelize), autenticación JWT, hashing de contraseñas con bcrypt, manejo de archivos con Multer, testing manual de endpoints con Postman, control de versiones con Git.

Por qué elegí este proyecto

Porque resume mi recorrido en el bootcamp de Desarrollo Full Stack JavaScript: partí de un servidor básico y terminé con una API backend real, segura y probada — que demuestra que puedo hacer crecer un proyecto de forma ordenada, sin romper lo que ya funcionaba.
